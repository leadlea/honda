# 要件定義書

## 概要

ベテラン人材マッチングシステムは、組織内の熟練社員（ベテラン）が自分のスキルや興味に合った新しい機会を見つけるためのシステムです。AIが生成する問診票を使用して個人の能力や希望を評価し、ベテランデータベースに情報を保存し、HONDAベテランバンクプラットフォームを通じて社内ポジションや社外機会のインテリジェントな推薦を提供します。

## 要件

### 要件1

**ユーザーストーリー:** ベテラン社員として、自分のスキルや希望についてAI生成の問診に答えたい。システムが私の能力とキャリアの興味を理解できるように。

#### 受入基準

1. ベテラン社員が問診にアクセスした時、システムはプロフィールに基づいてAIが生成した個人向けの質問を提示すること
2. ベテランが問診を完了した時、システムは回答を検証してベテランデータベースに保存すること
3. 質問を生成する時、AIは技術スキルとキャリア希望の両方を評価する質問を作成すること
4. ベテランが以前に問診を完了している場合、システムは回答の更新を許可すること

### 要件2

**ユーザーストーリー:** ベテラン社員として、自分のスキルや興味に合った機会のAI推薦を受けたい。専門知識を活用できる意味のある仕事を見つけるために。

#### 受入基準

1. システムがベテランのプロフィールを分析する時、個人向けの機会推薦を生成すること
2. 推薦を提示する時、システムは社内ポジションと社外機会の両方を含めること
3. ベテランが推薦を閲覧する時、システムは各機会がなぜプロフィールに合致するかを説明すること
4. 適切な機会が利用できない場合、システムはベテランに通知し、プロフィール更新を提案すること

### 要件3

**ユーザーストーリー:** ベテラン社員として、推薦された機会を確認して応募したい。自分のスキルやキャリア目標に合致するポジションを追求するために。

#### 受入基準

1. ベテランが推薦機会を確認する時、システムは役割と要件の詳細情報を表示すること
2. ベテランが合致する機会を見つけた時、システムは興味表明や応募を許可すること
3. ベテランが応募した時、システムは関連するステークホルダー（社内管理者や社外リクルーター）に通知すること
4. ベテランの応募状況が変更された時、システムは適切に更新すること

### 要件4

**ユーザーストーリー:** 外部リクルーターや企業として、HONDAベテランバンクにアクセスして適格な候補者を見つけたい。特定の役割に経験豊富な専門家を特定し、採用するために。

#### 受入基準

1. 外部関係者がベテランバンクにアクセスする時、システムは利用可能なベテランプロフィール（同意済み）を表示すること
2. 候補者を検索する時、外部関係者はスキル、経験、可用性でフィルタリングできること
3. 外部関係者が適切な候補者を特定した時、システムはプラットフォームを通じて初期接触を促進すること
4. ベテランが外部公開に同意している場合、そのプロフィールは公開ベテランバンクに含まれること

### 要件5

**ユーザーストーリー:** システム管理者として、ベテランプロフィールと機会データを管理したい。プラットフォームが正確で最新の情報を維持するために。

#### 受入基準

1. ベテランデータを管理する時、システムはデータプライバシーとセキュリティコンプライアンスを確保すること
2. ベテランがプロフィールを更新する時、システムは監査目的でバージョン履歴を維持すること
3. 機会が投稿される時、システムは適切に検証し分類すること
4. AI質問を生成する時、システムは質問が関連性があり偏見のないものであることを確保すること

### 要件6

**ユーザーストーリー:** ベテラン社員として、自分のスキルと経験に基づいたユニークなビジネスタイトルを生成してもらいたい。自分の専門性を効果的にアピールするために。

#### 受入基準

1. システムがベテランのプロフィールを分析する時、スキル、経験、専門分野に基づいてユニークなビジネスタイトルを生成すること
2. 生成されたタイトルがベテランの専門性と価値提案を明確に表現すること
3. ベテランが生成されたタイトルを確認し、必要に応じて修正や再生成を要求できること
4. タイトルが社内外での検索やマッチングに活用されること

### 要件7

**ユーザーストーリー:** ベテラン社員として、プロフィールの可視性とデータ共有をコントロールしたい。プライバシーとキャリア転換の希望を管理するために。

#### 受入基準

1. プロフィールを設定する時、ベテランは可視性設定（社内のみ、外部公開など）を選択できること
2. ベテランがプライバシー設定を変更したい時、システムは可視性設定のリアルタイム更新を許可すること
3. 外部関係者がプロフィールを閲覧する時、システムはベテランが共有に同意した情報のみを表示すること
4. ベテランがプロフィールを非公開にすることを選択した場合、外部可視性から即座に削除されること
