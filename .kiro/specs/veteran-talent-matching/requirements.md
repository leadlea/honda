# 要件定義書

## 概要

双日テックイノベーション：AI人材発掘・配置マッチングMVP（AI CoE支援）は、社内におけるAI人材の発掘と適材配置を支援する仕組みです。「AI内製化を前進させるための人材発掘と適材配置」という考え方のもと、AIスキル棚卸し（セルフ診断）を起点に、社内AI人材候補（社員）のスキル／経験プロファイルを整備し、AIポジションオーナー（各部門／AI CoE）がAIポジション（社内公募）／AIプロジェクトを相互にマッチングできる状態を実現します。

※本MVPは、既存のコード／API／データ構造を変更せず、文言・表現を新用語準拠に統一することを目的とします。

## 要件

### 要件1

**ユーザーストーリー:** 社内AI人材候補（社員）として、自分のスキルや経験、希望条件についてAIスキル棚卸し（セルフ診断）に回答したい。プラットフォームが私の強みと配置可能性を理解できるように。

#### 受入基準

1. 社内AI人材候補がAIスキル棚卸しにアクセスした時、システムはプロフィールに基づいてAIが生成した個人向けの質問を提示すること
2. 社内AI人材候補がAIスキル棚卸しを完了した時、システムは回答を検証して社内AI人材候補データベースに保存すること
3. 質問を生成する時、AIは技術スキル・実務経験・希望条件（配置形態や働き方）の両方を評価する質問を作成すること
4. 社内AI人材候補が以前にAIスキル棚卸しを完了している場合、システムは回答の更新を許可すること

### 要件2

**ユーザーストーリー:** 社内AI人材候補（社員）として、自分のスキルや希望条件に合ったAIポジション（社内公募）／AIプロジェクトのAIレコメンドを受けたい。自分の強みを活かし、成長につながる機会を見つけるために。

#### 受入基準

1. システムが社内AI人材候補のプロフィールを分析する時、個人向けのAIポジション／プロジェクト レコメンドを生成すること
2. レコメンドを提示する時、システムは配置形態の異なる機会を含められること（例：プロジェクト型、期間限定など）
3. 社内AI人材候補がレコメンドを閲覧する時、システムは各機会がなぜプロフィールに合致するかを説明すること
4. 適切な機会が利用できない場合、システムは社内AI人材候補に通知し、プロフィール更新を提案すること

### 要件3

**ユーザーストーリー:** 社内AI人材候補（社員）として、レコメンドされたAIポジションを確認して自薦応募したい。自分のスキルとキャリア意向に合致する機会を追求するために。

#### 受入基準

1. 社内AI人材候補がAIポジションを確認する時、システムは役割と要件の詳細情報を表示すること
2. 社内AI人材候補が合致する機会を見つけた時、システムは自薦応募を許可すること
3. 社内AI人材候補が自薦応募した時、システムは関連するステークホルダー（AIポジションオーナー／AI CoE運営／管理者など）に通知すること
4. 応募状況が変更された時、システムは適切に更新すること

### 要件4

**ユーザーストーリー:** AIポジションオーナー（各部門／AI CoE）として、社内ポジション公開・検索画面上で同意済みの社内AI人材候補プロファイルを検索し、適切な人材を見つけて初期接触を行いたい。AIポジションの成立を円滑にするために。

#### 受入基準

1. AIポジションオーナーがプラットフォームにアクセスする時、システムは利用可能な社内AI人材候補プロフィール（同意済み）を表示すること
2. 候補者を検索する時、AIポジションオーナーはスキル、経験、可用性などでフィルタリングできること
3. AIポジションオーナーが適切な候補者を特定した時、システムはプラットフォームを通じて初期接触（仲介）を促進すること
4. 社内AI人材候補が共有（公開）に同意している場合、そのプロフィールは社内AI人材候補検索に含まれること

### 要件5

**ユーザーストーリー:** AI CoE運営／管理者として、社内AI人材候補プロフィールとAIポジションデータを管理したい。プラットフォームが正確で最新の情報を維持し、適材配置が回る状態を保つために。

#### 受入基準

1. データを管理する時、システムはデータプライバシーとセキュリティコンプライアンスを確保すること
2. 社内AI人材候補がプロフィールを更新する時、システムは監査目的でバージョン履歴を維持すること
3. AIポジションが投稿される時、システムは適切に検証し分類すること
4. AIが質問やレコメンドを生成する時、システムは内容が関連性があり偏見のないものであることを確保すること

### 要件6

**ユーザーストーリー:** 社内AI人材候補（社員）として、自分のスキルと経験に基づいた「AIスキルポートフォリオ見出し（アピール肩書き）」を生成してもらいたい。自分の専門性を効果的に伝えるために。

#### 受入基準

1. システムが社内AI人材候補のプロフィールを分析する時、スキル、経験、専門分野に基づいて見出し（肩書き）を生成すること
2. 生成された見出しが社内AI人材候補の専門性と価値提案を明確に表現すること
3. 社内AI人材候補が生成された見出しを確認し、必要に応じて修正や再生成を要求できること
4. 見出しが検索やマッチングの文脈で活用されること

### 要件7

**ユーザーストーリー:** 社内AI人材候補（社員）として、プロフィールの共有範囲とデータ共有をコントロールしたい。プライバシーと安心して適材配置に参加できる状態を両立するために。

#### 受入基準

1. プロフィールを設定する時、社内AI人材候補は共有範囲（部門内公開、全社公開など）を選択できること
2. 社内AI人材候補が共有範囲設定を変更したい時、システムはリアルタイム更新を許可すること
3. AIポジションオーナーがプロフィールを閲覧する時、システムは社内AI人材候補が共有に同意した情報のみを表示すること
4. 社内AI人材候補が非公開を選択した場合、社内AI人材候補検索の対象から即座に除外されること
