# 要件定義書

## 概要

製造業プラチナアドバイザリー・プラットフォーム（Platinum Advisory）は、製造業における人材の流動化とスキル資産化を支援する仕組みです。「人材派遣ではない。人材不足解消でもない。人を活かす、新しい製造業の生態系。」という考え方のもと、AIによるスキル棚卸し（アドバイザリー問診）を起点に、登録人材（製造業ワーカー）のスキル／経験プロファイルを整備し、参加企業（シーズ企業／受入企業）が参画機会（出向／兼務／プロジェクト）を相互にマッチングできる状態を実現します。

※本MVPは、既存のコード／API／データ構造を変更せず、文言・表現をPlatinum Advisory準拠に統一することを目的とします。

## 要件

### 要件1

**ユーザーストーリー:** 登録人材（製造業ワーカー）として、自分のスキルや経験、希望条件についてAIによるスキル棚卸し（アドバイザリー問診）に回答したい。プラットフォームが私の強みと参画可能性を理解できるように。

#### 受入基準

1. 登録人材が問診にアクセスした時、システムはプロフィールに基づいてAIが生成した個人向けの質問を提示すること
2. 登録人材が問診を完了した時、システムは回答を検証して登録人材データベースに保存すること
3. 質問を生成する時、AIは技術スキル・実務経験・希望条件（参画形態や働き方）の両方を評価する質問を作成すること
4. 登録人材が以前に問診を完了している場合、システムは回答の更新を許可すること

### 要件2

**ユーザーストーリー:** 登録人材（製造業ワーカー）として、自分のスキルや希望条件に合った参画機会（出向／兼務／プロジェクト）のAIレコメンドを受けたい。自分の強みを活かし、成長につながる機会を見つけるために。

#### 受入基準

1. システムが登録人材のプロフィールを分析する時、個人向けの参画機会レコメンドを生成すること
2. レコメンドを提示する時、システムは参画形態の異なる機会を含められること（例：プロジェクト型、期間限定など）
3. 登録人材がレコメンドを閲覧する時、システムは各機会がなぜプロフィールに合致するかを説明すること
4. 適切な機会が利用できない場合、システムは登録人材に通知し、プロフィール更新を提案すること

### 要件3

**ユーザーストーリー:** 登録人材（製造業ワーカー）として、レコメンドされた参画機会を確認して参画申請（興味表明）したい。自分のスキルとキャリア意向に合致する機会を追求するために。

#### 受入基準

1. 登録人材が参画機会を確認する時、システムは役割と要件の詳細情報を表示すること
2. 登録人材が合致する機会を見つけた時、システムは参画申請（興味表明）を許可すること
3. 登録人材が申請した時、システムは関連するステークホルダー（参加企業担当者／運営管理者など）に通知すること
4. 申請状況が変更された時、システムは適切に更新すること

### 要件4

**ユーザーストーリー:** 参加企業（受入企業／シーズ企業）の担当者として、Platinum Advisory上で同意済みの登録人材プロファイルを検索し、適切な人材を見つけて初期接触を行いたい。参画機会の成立を円滑にするために。

#### 受入基準

1. 参加企業担当者がプラットフォームにアクセスする時、システムは利用可能な登録人材プロフィール（同意済み）を表示すること
2. 候補者を検索する時、参加企業担当者はスキル、経験、可用性などでフィルタリングできること
3. 参加企業担当者が適切な候補者を特定した時、システムはプラットフォームを通じて初期接触（仲介）を促進すること
4. 登録人材が共有（公開）に同意している場合、そのプロフィールは参加企業向けの公開検索に含まれること

### 要件5

**ユーザーストーリー:** 運営管理者として、登録人材プロフィールと参画機会データを管理したい。プラットフォームが正確で最新の情報を維持し、安心して共助が回る状態を保つために。

#### 受入基準

1. データを管理する時、システムはデータプライバシーとセキュリティコンプライアンスを確保すること
2. 登録人材がプロフィールを更新する時、システムは監査目的でバージョン履歴を維持すること
3. 参画機会が投稿される時、システムは適切に検証し分類すること
4. AIが質問やレコメンドを生成する時、システムは内容が関連性があり偏見のないものであることを確保すること

### 要件6

**ユーザーストーリー:** 登録人材（製造業ワーカー）として、自分のスキルと経験に基づいた「スキルポートフォリオ見出し（アピール肩書き）」を生成してもらいたい。自分の専門性を効果的に伝えるために。

#### 受入基準

1. システムが登録人材のプロフィールを分析する時、スキル、経験、専門分野に基づいて見出し（肩書き）を生成すること
2. 生成された見出しが登録人材の専門性と価値提案を明確に表現すること
3. 登録人材が生成された見出しを確認し、必要に応じて修正や再生成を要求できること
4. 見出しが検索やマッチングの文脈で活用されること

### 要件7

**ユーザーストーリー:** 登録人材（製造業ワーカー）として、プロフィールの共有範囲とデータ共有をコントロールしたい。プライバシーと安心して共助に参加できる状態を両立するために。

#### 受入基準

1. プロフィールを設定する時、登録人材は共有範囲（参加企業向け公開、限定公開など）を選択できること
2. 登録人材が共有範囲設定を変更したい時、システムはリアルタイム更新を許可すること
3. 参加企業担当者がプロフィールを閲覧する時、システムは登録人材が共有に同意した情報のみを表示すること
4. 登録人材が非公開を選択した場合、公開検索の対象から即座に除外されること
