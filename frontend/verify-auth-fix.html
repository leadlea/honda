2. ブラウザテスト / Browser Testing

📝 手動テスト手順 / Manual Testing Steps:
  • ログインフローテスト / Login Flow Test MANUAL
    1. アプリケーションを起動: npm start
    2. ベテランユーザーとしてログイン
    3. ダッシュボードに移動
    4. 「おすすめ」ボタンをクリック
    5. 401エラーなしでレコメンデーションが表示されることを確認
  • トークン検証テスト / Token Verification Test MANUAL
    1. ブラウザのDevToolsを開く (F12)
    2. 「Network」タブに移動
    3. 「おすすめ」ボタンをクリック
    4. APIリクエストを確認: GET /recommendations/{userId}
    5. Request Headersを確認:
    Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9... Content-Type: application/json
    1. レスポンスステータスが 200 OK であることを確認
  • コンソールログ確認 / Console Log Check MANUAL
    1. ブラウザのDevToolsで「Console」タブを開く
    2. レコメンデーションを取得
    3. 以下のエラーがないことを確認:
    ❌ 401 (Unauthorized) ❌ Authorization token required ❌ Failed to fetch recommendations: Unauthorized
    ✅ GET /recommendations/user-123 200 (OK)

3. エラーハンドリングテスト / Error Handling Test

  • 未認証アクセステスト / Unauthenticated Access Test MANUAL
    1. ブラウザのセッション/クッキーをクリア
    2. レコメンデーションにアクセスを試みる
    3. 日本語のエラーメッセージが表示されることを確認
    4. ログインページにリダイレクトされることを確認
